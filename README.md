A curated collection of **free, instant, browser-based developer tools** for JSON formatting, data conversion, encoding, security, and more. All tools run 100% client-side — no uploads, no login, no data leaves your browser.

**🌐 Live Site:** [jsonformat.org](https://jsonformat.org)

---

## 🔧 JSON Tools

- [**JSON Formatter**](https://jsonformat.org/json-formatter) — Beautify, validate, and minify JSON with syntax highlighting
- [**JSON Viewer**](https://jsonformat.org/json-viewer) — Interactive tree viewer with collapsible nodes and search
- [**JSON Validator**](https://jsonformat.org/json-validator) — Validate JSON syntax and get detailed error messages
- [**JSON Minify**](https://jsonformat.org/json-minify) — Remove whitespace and compress JSON instantly
- [**JSON Compare**](https://jsonformat.org/json-compare) — Side-by-side diff with color-coded additions, deletions, and changes
- [**JSON Escape**](https://jsonformat.org/json-escape) — Escape or unescape special characters for JSON strings

## 🔄 Data Format Converters

### JSON Converters
- [**JSON to CSV**](https://jsonformat.org/json-to-csv) — Convert JSON arrays to CSV with custom delimiters
- [**JSON to YAML**](https://jsonformat.org/json-to-yaml) — Transform JSON to clean, readable YAML
- [**JSON to XML**](https://jsonformat.org/json-to-xml) — Convert JSON objects to XML with configurable root element
- [**JSON to TOML**](https://jsonformat.org/json-to-toml) — Generate TOML config files from JSON
- [**JSON to TOON**](https://jsonformat.org/json-to-toon) — Convert JSON to TOON format

### To JSON Converters
- [**CSV to JSON**](https://jsonformat.org/csv-to-json) — Parse CSV files into JSON arrays or objects
- [**YAML to JSON**](https://jsonformat.org/yaml-to-json) — Convert YAML to valid JSON instantly
- [**XML to JSON**](https://jsonformat.org/xml-to-json) — Transform XML documents to JSON
- [**TOML to JSON**](https://jsonformat.org/toml-to-json) — Parse TOML config files to JSON
- [**TOON to JSON**](https://jsonformat.org/toon-to-json) — Convert TOON format to JSON

### Other Format Tools
- [**CSV Formatter**](https://jsonformat.org/csv-formatter) — Format and validate CSV with syntax highlighting
- [**YAML Formatter**](https://jsonformat.org/yaml-formatter) — Beautify and validate YAML files
- [**XML Formatter**](https://jsonformat.org/xml-formatter) — Format and validate XML with indentation
- [**TOML Formatter**](https://jsonformat.org/toml-formatter) — Format and validate TOML config files
- [**TOON Formatter**](https://jsonformat.org/toon-formatter) — Format and validate TOON files

## 🔐 Security Tools

- [**Hash Generator**](https://jsonformat.org/hash-generator) — Generate MD5, SHA-1, SHA-256, SHA-512 hashes instantly
- [**Password Generator**](https://jsonformat.org/password-generator) — Create secure random passwords with custom rules
- [**AES Encrypt/Decrypt**](https://jsonformat.org/aes-encrypt) — AES-128/192/256 encryption and decryption
- [**HMAC Generator**](https://jsonformat.org/hmac-generator) — Generate HMAC signatures with multiple algorithms
- [**RSA Encrypt/Decrypt**](https://jsonformat.org/rsa-encrypt) — RSA public-key encryption and decryption

## 🛠️ Encode & Utils

- [**Base64 Encode/Decode**](https://jsonformat.org/base64-encode) — Encode text or files to Base64 and decode Base64 strings
- [**URL Encode/Decode**](https://jsonformat.org/url-encode) — Encode and decode URL parameters and query strings
- [**JWT Decoder**](https://jsonformat.org/jwt-decoder) — Inspect JWT header, payload, and claims with signature verification
- [**Regex Tester**](https://jsonformat.org/regex-tester) — Test regular expressions with live match highlighting
- [**Timestamp Converter**](https://jsonformat.org/timestamp-converter) — Convert between Unix timestamps and human-readable dates
- [**Unit Converter**](https://jsonformat.org/unit-converter) — Convert length, weight, temperature, and more
- [**Calculator**](https://jsonformat.org/calculator) — Simple and scientific calculator
- [**Cron Expression Generator**](https://jsonformat.org/cron-generator) — Build cron schedules with a visual editor
- [**QR Code Generator**](https://jsonformat.org/qr-generator) — Generate QR codes for text, URLs, and more

## ✨ Features

- ✅ **100% Client-Side** — All processing happens in your browser. No server uploads, no privacy concerns.
- ⚡ **Instant & Free** — No registration, no rate limits, no ads blocking content.
- 🌍 **Multilingual** — Available in 9 languages: English, 中文, 日本語, 한국어, Deutsch, Español, Français, Português, Русский.
- 📱 **Responsive Design** — Works seamlessly on desktop, tablet, and mobile.
- 🔗 **URL Sharing** — Share compressed data via URL hash for collaboration.

---

## 🚀 Tech Stack

- **Pure HTML/CSS/JavaScript** — No frameworks, no build tools, no dependencies.
- **Self-Contained** — Each tool is a single HTML file with inlined styles and scripts.
- **Static Hosting** — Deployed on Cloudflare Pages for global performance.
